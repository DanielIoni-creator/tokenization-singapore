## 📝 项目描述

**Tokenization Singapore** 是一个用于管理和分析资产代币化相关数据的项目。目标是创建工具和文档，以促进对代币化系统的理解和实施，特别关注用例和最佳实践。

目前，项目正在开发中，包括以下模块：
- 数据管理（`data/` 文件夹）
- 处理脚本（`scripts/`）
- 技术文档（`docs/`）
- 使用示例（`examples/`）
- 自动化测试（`tests/`）
