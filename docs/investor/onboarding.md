# Investor Onboarding Process

## Fasi
1. **KYC/AML Verification**
   - Documenti di identità
   - Prova di residenza
   - Screening anti-riciclaggio

2. **Accredited Investor Verification**
   - Net worth > S$2M
   - Income > S$300K/anno
   - Portfolio > S$8M (HK standard)

3. **Investment Agreement**
   - Token purchase agreement
   - Subscription agreement
   - Risk disclosure

4. **Token Issuance**
   - Wallet creation
   - Token transfer
   - Portfolio dashboard access
