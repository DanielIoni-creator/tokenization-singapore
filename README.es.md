## 📝 Descripción del Proyecto

**Tokenization Singapore** es un proyecto para la gestión y análisis de datos relacionados con la tokenización de activos. El objetivo es crear herramientas y documentación para facilitar la comprensión e implementación de sistemas de tokenización, con un enfoque particular en casos de uso y mejores prácticas.

Actualmente, el proyecto está en fase de desarrollo e incluye módulos para:
- Gestión de datos (carpeta `data/`)
- Scripts para procesamiento (`scripts/`)
- Documentación técnica (`docs/`)
- Ejemplos de uso (`examples/`)
- Pruebas automatizadas (`tests/`)

## 💰 Programa "Spiccioli in Monero" (Monedas en Monero)

Este proyecto participa en el sistema de micro-recompensas **"Spiccioli in Monero"**, que permite a cualquier persona contribuir con pequeñas correcciones y ganar Monero (XMR). La filosofía es simple: **incluso la contribución más pequeña tiene valor y merece una recompensa**.

### ¿Cómo funciona?

1.  **Busca un issue con etiqueta 💰:** Ve a la sección [Issues del proyecto](https://github.com/DanielIoni-creator/tokenization-singapore/issues) y filtra por las etiquetas:
    *   `💰 spicciolo`: 0.0005 XMR (≈ €0.10) - para correcciones de errores tipográficos, enlaces rotos.
    *   `💰 spiccioletto`: 0.001 XMR (≈ €0.20) - para correcciones de advertencias, comentarios, pequeñas mejoras.
    *   `💰 spicciona`: 0.003 XMR (≈ €0.60) - para pruebas unitarias, actualizaciones del README.
    *   `💰 superspiccio`: 0.01 XMR (≈ €2.00) - para pequeñas funcionalidades o refactorización.

2.  **Toma el issue:** Comenta `¡Yo lo tomo!` para asignártelo. Tienes **24 horas** para abrir una Pull Request (PR).

3.  **Abre la PR:** Proporciona la solución e incluye tu **dirección pública de Monero** en la descripción de la PR para recibir el pago.

4.  **Recibe el pago:** Después de que la PR haya sido revisada y fusionada, recibirás la recompensa en XMR dentro de las 24 horas.

### ¿Por qué Monero?

*   **Privacidad:** No se necesitan datos bancarios ni KYC.
*   **Micropagos:** Las comisiones son bajas, lo que hace posibles incluso las recompensas más pequeñas.
*   **Global:** Accesible para colaboradores de todo el mundo.

Para más detalles, consulta nuestra [CONTRIBUTING.md](CONTRIBUTING.md) y la transparencia del fondo en [FUNDING.md](FUNDING.md).
