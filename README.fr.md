## 📝 Description du Projet

**Tokenization Singapore** est un projet de gestion et d'analyse de données liées à la tokenisation d'actifs. L'objectif est de créer des outils et une documentation pour faciliter la compréhension et la mise en œuvre des systèmes de tokenisation, avec un accent particulier sur les cas d'utilisation et les bonnes pratiques.

Actuellement, le projet est en cours de développement et comprend des modules pour :
- La gestion des données (dossier `data/`)
- Des scripts de traitement (`scripts/`)
- La documentation technique (`docs/`)
- Des exemples d'utilisation (`examples/`)
- Des tests automatisés (`tests/`)

## 💰 Programme "Spiccioli in Monero" (Monnaie en Monero)

Ce projet participe au système de micro-primes **"Spiccioli in Monero"**, qui permet à chacun de contribuer avec de petites corrections et de gagner du Monero (XMR). La philosophie est simple : **même la plus petite contribution a de la valeur et mérite une récompense**.

### Comment ça fonctionne ?

1.  **Trouvez un ticket avec une étiquette 💰 :** Allez dans la section [Tickets du projet](https://github.com/DanielIoni-creator/tokenization-singapore/issues) et filtrez par étiquettes :
    *   `💰 spicciolo` : 0,0005 XMR (≈ 0,10 €) - pour les fautes de frappe, les liens brisés.
    *   `💰 spiccioletto` : 0,001 XMR (≈ 0,20 €) - pour les corrections d'avertissements, les commentaires, les petites améliorations.
    *   `💰 spicciona` : 0,003 XMR (≈ 0,60 €) - pour les tests unitaires, les mises à jour du README.
    *   `💰 superspiccio` : 0,01 XMR (≈ 2,00 €) - pour les petites fonctionnalités ou le refactoring.

2.  **Prenez le ticket :** Commentez `Je le prends !` pour vous l'attribuer. Vous avez **24 heures** pour ouvrir une Pull Request (PR).

3.  **Ouvrez la PR :** Fournissez la solution et incluez votre **adresse publique Monero** dans la description de la PR pour recevoir le paiement.

4.  **Recevez le paiement :** Après que la PR a été révisée et fusionnée, vous recevrez la récompense en XMR dans les 24 heures.

### Pourquoi Monero ?

*   **Confidentialité :** Aucune donnée bancaire ni KYC requis.
*   **Micro-paiements :** Les frais sont bas, ce qui rend possibles même les plus petites récompenses.
*   **Mondial :** Accessible aux contributeurs du monde entier.

Pour plus de détails, consultez notre [CONTRIBUTING.md](CONTRIBUTING.md) et la transparence du fonds dans [FUNDING.md](FUNDING.md).
